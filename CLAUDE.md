# c-magic

A small operating system written from scratch, mainly to learn C. The full roadmap is in [plan.md](plan.md).

## Current status

- **Active phase:** Phase 0: C foundations
- **Current step:** `strcmp`, then `memcpy` (`strlen` is done)

When a step or phase is finished, update this section in the same change.

## Working agreement

The user writes the code. Explain concepts, review their work and help debug rather than writing it for them.

Give one task at a time and keep it short. Wait until the user finishes it before giving the next one.
